# Synthetic scanner fixtures

All PNGs here are generated by `node scripts/generate-fixtures.mjs` using only Node standard modules. They contain synthetic test text, not real documents, and explicitly say SIMULATED. They are safe to commit. Each PNG includes a Source text chunk identifying its generator. Images are 850 × 1100 pixels; simulation does not resample them or claim real 300 dpi capture.

- `basic`: three ordered feeder pages.
- `duplex`: two sheets, ordered front then back using `a-front` / `b-back` filenames.
- `edge-cases`: mostly blank, faint, dirty, and rotated sheets. All are retained.

Set `DIGITALARCH_FIXTURES` to an explicitly chosen **flat directory of PNG files** to use private external fixtures instead. They are read in lexicographic filename order and never copied here. Names determine front/back order; name them accordingly. The single-page scenario takes the first image; other non-error scenarios use all images. Paper jam retains exactly the first two. Use the bundled fixtures to demonstrate the actual blank/duplex image content.

Never put sensitive documents in this directory. Existing `scan-test-*.png` outputs are ignored, not imported.
